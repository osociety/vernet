Vernet으로 집이나 사무실 네트워크를 직접 제어해 보세요. 네트워크 정보를 손에 쥐게 해 주는 무료 오픈소스 도구 모음입니다.

느린 연결을 진단하든, Wi-Fi에 누가 접속 중인지 확인하든, 기기에 접근할 수 있는지 점검하든 — Vernet은 기술 지식 없이도 명확하고 쉬운 답을 제공합니다.

🔍 내 네트워크에는 무엇이 있을까?
로컬 Wi-Fi에 연결된 모든 기기를 IP 주소와 이름과 함께 보세요. 내 연결을 누구와 무엇이 함께 쓰는지 정확히 알 수 있습니다.

📡 인터넷이 정상 동작 중일까?
ping 테스트로 웹사이트나 기기가 응답하는지 확인하세요. 끊김과 지연도 몇 초면 발견할 수 있습니다.

⚡ 내 연결 속도는 얼마나 될까?
기본 제공 속도 테스트로 실제 다운로드와 업로드 속도를 측정하세요. 앱을 벗어나지 않고 정확한 결과를 얻습니다.

🔓 어떤 서비스가 열려 있을까?
기기의 열린 포트를 스캔해 어떤 서비스에 접근할 수 있는지 확인하세요. 홈 네트워크 보안 상태를 파악하는 데 도움이 됩니다.

🌐 이 주소 뒤에는 무엇이 있을까?
기본 제공 DNS 도구로 도메인 이름을 찾고, IP를 해석하고, 인터넷에서 주소가 어떻게 연결되는지 추적할 수 있습니다.
