自宅やオフィスのネットワークを Vernet で思いどおりに。ネットワークの状況をあなたの目で確認できる、無料のオープンソース ツールキットです。

接続が遅い原因を調べたいときも、Wi-Fi に接続中の機器を知りたいときも、機器にアクセスできるか試したいときも、Vernet は専門知識がなくても分かりやすい答えを返します。

🔍 ネットワークには何がありますか?
ローカルの Wi-Fi に接続されているすべての機器を、IP アドレスや名前と一緒に確認できます。誰が・何が接続を共有しているのか、はっきり分かります。

📡 インターネットは動いていますか?
ping テストを実行して、Web サイトや機器が応答しているかを確認できます。通信の途切れや遅れも数秒で見つかります。

⚡ 接続速度はどれくらいですか?
内蔵の速度テストで、実際のダウンロードとアップロードの速度を測定できます。アプリから離れずに正確な結果が得られます。

🔓 公開されているサービスは何ですか?
機器をスキャンしてオープンなポートを探し、どのサービスに到達できるかを確認できます。ネットワークのセキュリティ状態の把握に役立ちます。

🌐 このアドレスの先には何がありますか?
内蔵の DNS ツールでドメイン名を検索し、IP を解決し、アドレスがインターネット上でどうマッピングされているかを確認できます。

✅ 無料かつオープンソース
Vernet は無料で、ソースは GitHub で公開されています: https://github.com/osociety/vernet
